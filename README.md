# Department of Defense Leave Request Form

This is a digital version of the Department of Defense Leave Request Form, designed to be easily printable and downloadable as a PDF.

## Features
- Clean, professional design
- Print/Download as PDF functionality
- Responsive layout
- Official DoD styling

## Usage
Simply open the form in a web browser, review the information, and use the "Print/Download as PDF" button to save or print the form.

## Deployment
This form is deployed using GitHub Pages. You can access it at the GitHub Pages URL once deployment is complete.

## Local Development
To run this locally:
1. Clone the repository
2. Open `index.html` in your web browser
